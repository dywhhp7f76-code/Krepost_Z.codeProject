# Плагины Obsidian для vault Атакера

Поставь в этом vault (Settings → Community plugins), чтобы удобно рыть KB:

| Плагин | Зачем |
|--------|--------|
| **Dataview** | таблицы по `tags: [атакер]` / статусам ✅⏸❌ |
| **Omnisearch** | полнотекст по HTML-снимкам и PDF (если индексирует) |
| **PDF++** или встроенный PDF | читать `OWASP-Top-10-for-LLMs-v2025.pdf` |
| **Templater** | шаблоны карточек техник ATLAS / labs |
| **Local REST API** *(опц.)* | потом связать с Ataker harness |
| **Git** *(опц.)* | синк с этим репо |

Core: **Outgoing links**, **Graph view**, **Search**.

Не ставь сюда «боевые» плагины с облачным AI без карантина — dirty-zone.
