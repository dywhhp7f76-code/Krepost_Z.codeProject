# Obsidian Agents (Air)

Чат для **создания своих агентов** + готовые клиппер/тема.  
Пишут **только** в Inbox — ты сам выбираешь, что куда переносить.

## Без ИИ на Air?

**Не сложно.** Создание агентов работает по шаблонам (rules), без локальной модели.  
Если жива Крепость на Studio (`http://10.0.0.1:8000`) — разбор запроса чуть умнее (опция в чате).

Это **не** боевая Крепость и **не** зоопарк.

## Вкладки

1. **Создать агента** — чат: опиши агента словами → JSON в `agents/user/`
2. **Мои агенты** — список, запуск, удаление
3. **С сайта (URL)** — страница → markdown в Inbox
4. **По теме** — тема → черновик (LM Studio на Air, если есть)
5. **Inbox** — последние файлы

Типы агентов: `clip` · `topic` · `checklist` · `note`

## Команды в чате

- обычный текст → создать агента  
- `/list` — список  
- `/run id текст` — запуск  
- `/del id` — удалить  
- `помощь` — подсказка  

## Запуск

Ярлык **Obsidian Agents** / `start.command`  
→ `http://127.0.0.1:8765`

### Все чаты в Safari «Личный»

Ярлык **Личные чаты** (Программы / Рабочий стол) или `open_safari_lichnyy.command`  
→ вкладки в группе Safari **Личный**: хаб `/hub` · Крепость · Agents · Claude.

Inbox по умолчанию:  
`…/Krepost_Z.codeProject/vault/09-Inbox/from_agents`
